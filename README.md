# SmartCGPA – Academic Performance Analyzer

A C++ based academic performance analysis tool developed as part
of the CodeAlpha C++ Programming Internship.

## 🎯 Objective

To calculate GPA/CGPA based on course grades and credit hours
while providing additional academic performance insights.

## ✨ Features

- GPA calculation
- Overall CGPA calculation
- Course-wise result display
- Credit-weighted calculations
- Grade validation
- Performance classification
- Highest/lowest performing course
- Target CGPA calculator
- Input validation
- Menu-driven interface

## 🛠️ Technologies

- C++
- STL Vector
- Structures
- Functions
- Loops
- Conditional Statements
- Input Validation
