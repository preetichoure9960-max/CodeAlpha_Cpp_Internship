# SmartCGPA – Project Report

## 1. Introduction

SmartCGPA is a console-based C++ application developed as part
of the CodeAlpha C++ Programming Internship.

The application calculates GPA based on course grades and credit
hours and provides additional academic performance information.

## 2. Problem Statement

Students often need to calculate their academic performance using
different grades and credit hours. Manual calculations can be
time-consuming and may lead to calculation errors.

SmartCGPA provides an automated solution for these calculations.

## 3. Objectives

- Calculate GPA using credit-weighted grade points.
- Accept course details from the user.
- Validate grades and credit hours.
- Display course-wise academic results.
- Classify overall academic performance.
- Identify high and low performing courses.
- Calculate the GPA required to reach a target CGPA.

## 4. Features

### GPA Calculation

The application calculates GPA using the grade point and credit
hours of each course.

### Academic Report

The application displays:

- Course name
- Credit hours
- Grade
- Grade point
- Total credits
- Final GPA

### Performance Analysis

The application provides an overall performance classification
and identifies the highest and lowest performing courses.

### Target CGPA Calculator

The application estimates the GPA required in a future semester
to reach a desired CGPA.
